# 方法与数据范围

使用 OpenAI CLIP ViT-B/32 初始化。现存历史模型由视觉塔微调、局部 O3 Adapter 与 Part-Token Adapter 组成；局部特征残差共享分类头。推理使用固定四尺度与水平翻转。该描述来自现有代码及配置，不构成所有组合结构已获赛事认可的独立证明。

初赛训练清单 103,218 张，测试 24,967 张，类别映射为 500 类。全量训练父模型已见原验证集：原验证 10,316 个样本对应 10,198 个字节内容组。本地指标只能标记重叠诊断，不能当作未见样本泛化结果。字节哈希分组不保证排除近重复图。

范数变体相对同协议原父模型降低 3.4005 个百分点，固定变体被拒绝。结论不推广到其他分类器解耦方法。历史 pa0.90 使用不同校准来源，不能把跨协议差值全部归因于模型参数变化，也不把其成绩转移到新校准文件。

# 重建与监督诊断

缺失的官方 CLIP 原始特征已在新的本地目录重建。103218×512 fp32 张量全部有限，样本顺序与历史路径清单一致；旧张量缺失，不能证明位级或数值等价。

历史 trust 依赖已追到 cvt_v1、fullfit_r1_teacher_v1、selftrain_r1_teacher_v2_relaxed、selftrain_r2_teacher_v3_multiscale 四级。多个祖先模型缺失，完整训练闭合仍在进行。新权重和旧序列化哈希不能混为同一资产。

新增可选监督量日志记录真实抽样次数、唯一样本数、软目标转移、加权目标量及分类损失分母。它是监督暴露统计，不是真实梯度范数，也不能当作人工真值噪声率。尚未登记的头中尾分组不自动设定阈值。

# 校准与阶段隔离

正式推理不得从测试批次拟合偏置。无校准路径保留；拟合校准必须同时绑定模型、类别映射、视图与温度、样本来源和作用域。仅有 test_data_used=false 不足以证明来源可靠。

初赛学习产物不默认用于复赛或半决赛。官网口径按仓库 2026-09-11 记录为复赛 750 类、半决赛 500 类；实际阶段仍须核验当期正式清单。未来阶段完整训练、PDF交付口径及最终验收不能由本初赛报告代替。

# 可复现性限制与交付边界

合成软件演练已跑通特征、真实训练、推理和提交检查；这不是正式训练精度复现。正式配方的完整来源、校准政策、数值复现和干净环境验证仍有未完成工作。本 PDF 是可维护技术材料初稿，不标记研究验收或正式发布通过。

## 可证伪的问题

在相同官方CLIP初始化、384输入、组隔离划分、样本抽取、增强、更新数与评估下，
把原标签监督换成v1目标/可靠度，能否改善全量验证预测，并保住少样本类别？
teacher/kNN信号不是真值，teacher不是OOF；低权重和被筛除样本数不是已确认错标量。

共同修改为固定两轮、seed20260926、最终第2轮EMA；不按验证分选轮次或raw/EMA状态。

- 官方OpenAI CLIP ViT-B/32，全视觉塔＋线性头训练，88,233,966个FP32参数；
  CUDA运行使用BF16和activation checkpointing，448 LoRA和余弦头不进入本模型。
- 输入384，逻辑batch96、micro batch2、workers2（spawn，120秒加载超时）；
  每臂每轮1,393次更新，共2,786次，两臂总计5,572次；有放回抽样，drop_last87个抽样槽位。
- 两臂共用**原标签类频次**平方根倒数抽样，不按伪标签重算频次，不把可靠度用于采样。
  CPU准备时冻结两轮完整draw数组；每个重复抽样槽位独立但可重放地生成增强。
- AdamW：骨干LR3e-5、头LR5e-4、WD0.15，bias/一维参数不衰减；warmup1轮＋cosine，
  min LR ratio0.02，grad clip1，EMA0.9995每逻辑更新一次。
- RRC[0.35,1]、flip、ColorJitter0.5、RandAugment2/7、RandomErasing0.3；
  label smoothing0.15，Mixup0.2/CutMix1.0，混合概率0.8。
- Mixup/CutMix**先给两份标签贡献分别乘可靠度，再按同一实际混合比例组合**。
  分母是完整逻辑批次原始权重和；micro batch不各自归一化，零质量批次仍执行同一次
  AdamW/scheduler/EMA更新并记录，保持更新纪律。

这里的实验臂保留零权重图像槽位，图像仍可参与混合，分类标签贡献为零。
v1原学生训练会直接排除这些图像；本配对的安排用于隔离监督变化，不能称完整v1训练配方复现。

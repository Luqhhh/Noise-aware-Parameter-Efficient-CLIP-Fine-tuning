# P75 已有证据拆分复核：暂不选择新训练主线

**本轮只读取 P0 逐样本表和摘要，完成 CPU 统计。结论是：交集规则确实压缩覆盖，但当前参考证据尚不能支持大规模困难监督恢复，也不能把未知样本撤掉类别监督。** 不启动 P75_SUPPORTED_CE、旧三通道 R1 或 R2；不派生训练配置，不重复快照/近邻/OOF。本轮未操作 SAM；SAM 仍只完成已启动的固定实验后暂停，已提交记录仍无最终验证结果。

## 实测：哪些信号在排除样本

三路依次为近邻原标签 ≥12/20 票、原型 OOF、岭 OOF。完整八组合及结构条件拆分见[报告](../results/p75_evidence_recheck_20260929/report.md)，各类计数见[覆盖表](../results/p75_evidence_recheck_20260929/class_coverage.csv)。这里的“困难”仅指 L05 最终中心视图 `p_y<0.3` 或 top1 错分，不能恢复早期训练轨迹。

| 证据组合 | 训练样本 | 类别数 | 最终困难 |
|---|---:|---:|---:|
| 仅要求近邻阈值 | 32,399 | 648 | 8 |
| 仅要求原型 OOF 支持 | 64,413 | 748 | 265 |
| 仅要求岭 OOF 支持 | 75,060 | 750 | 293 |
| 两路 OOF 同时支持，不要求近邻阈值 | 59,369 | 745 | 115 |
| 三路同时通过，尚未加结构条件 | 30,335 | 631 | 5 |
| 三路通过且结构条件通过（旧原标签通道） | 30,258 | 630 | 3 |
| 三路全部未通过（000） | 53,260 | 750 | 13,898 |

近邻阈值单独就使 102 类零接受；原型为 2 类，岭为 0 类。两路 OOF 同时通过而近邻未通过的 **29,034** 张分布于 742 类，说明参考信号间存在大范围差异；其中困难 110 张，进一步排除自身内容组冲突后剩 28,609 张、困难 45 张。结构条件总共排除 3,527 张，均由自身组标签冲突引起；本表所有行已有 20 个独立近邻组。三路通过集合又被结构条件排除 77 张、1 个原本有支持的类别。

但全训练 **14,343** 张最终困难样本中，**13,898（96.90%）三路均未通过**。因此“只因交集过严而漏掉大量已有支持的困难样本”不获本次证据支持。某一路接受少不证明它错误；某一路预测原标签以外类别也不等于反对原标签的可靠证据。这里不调整阈值，不把单信号接受量转成训练准入。

## 本检查点的决定

支持原标签、反对原标签、单纯缺证据必须分开。当前只证明筛选器偏向已经学会的样本，并看到大量参考信号不足或相互分歧；不能区分其中标签争议与共同表征偏差的真实比例。

旧三通道配方把 103,407 张不确定训练图撤掉类别目标，**停止作为后续默认方案**。未来缺少可靠干预证据时，原有鲁棒监督 GCE 是默认退路和对照；这是防止破坏监督覆盖，不是冲 75 的新范式证据。旧 2,139 张代理与少量 CE 恢复均不获得新完整训练预算。R1/R2 代码准备和支持集合非空不构成开训许可。此轮交付后暂停，不继续补模型、调阈值或自动试跑。

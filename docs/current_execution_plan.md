# 已完成：T1 过度离散的零假设标定（2026-09-26，零 GPU）

**起因**：T0 §6 的过度离散（sd(z)=2.51）曾是「val 与 test 预测分布确有差异」的唯一本地证据，
但它缺一个对照 —— 逐类计数并非多项分布（近重复图成簇），sd(z) 可能**在任意两个不相交样本之间**
都大于 1。T1 把同一统计量算在**同一总体的两个随机不相交子样本**上，量出这个基线。

**结论三条：**

1. **T0 §6 被证实，不是小计数假象。** 同总体切分零分布 sd(z) = 1.0556 [0.99, 1.12]（1000 次最大 1.185）、
   chi²/dof = 1.1222、|z|>2 中位数 42；观察值 2.5128 / 6.3175 / 244 在 1000 次里**一次都没出现**（p_ge = 0.0000）。
   三种同总体设计（test 同尺度 14880/22564、test 等半、val 等半）与两条手臂结论一致。统计量本身标定良好。
2. **但「本地跨源代理」不存在。** 分辨力**只在 test 侧** —— 只用 val 的变体 sd(z) 中位数 1.0910，
   与 test 侧 1.0556 无实质差别。该统计量在单一总体下**恒为 ≈1**，读 2.51 的前提就是两侧不同总体，
   而那**需要 test 预测**。⇒「不碰测试集、规则合法的本地模型选择指标」这条路**关闭**。
3. **机制仍不可辨识。** 统计量比对的是**预测**分布且 test 标签不可得，
   无法区分「test 真实类别先验不同」与「漂移使预测分布变形」。弱方向证据（**不作结论用**）：
   同样本量 n=14880 下 val 覆盖 741 类、test 子样本覆盖 735 [732, 738]，test 预测**更集中**约 0.8%。

**净效果：本阶段没有新增本地判据**，仍只能由平台名额驱动 —— 又一条本地代理候选被关掉。
**不改判据、不派生候选、不占名额**（判据在脚本 docstring 内跑前写定，跑后未改）。

详见[T1 测量记录](rematch750_dispersion_null_20260926.md)、机器可读结果 `results/rematch750_dispersion_null_20260926.json`。

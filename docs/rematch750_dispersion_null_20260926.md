## 1. 一句话结论

**T0 §6 的过度离散是真的，不是小计数假象。** 把它算在「同一总体的两个随机不相交子样本」上，
sd(z) 的零分布是 **1.05 [0.99, 1.12]**；观察值 **2.51** 在 1000 次重复中**一次都没出现**。
三种同总体设计（test 同尺度切分 / test 等半 / val 等半）与两条手臂结论一致。

**但这不产生「本地跨源代理」。** 能分辨的统计量**需要 test 预测**；任何只用 val 的变体
都与零假设无法区分（§3.3）。因此 T0 的发现**不能**转成一条不碰测试集的模型选择指标。

**机制仍不可辨识** —— 统计量比对的是**预测**分布且 test 标签不可得，
无法区分「test 真实类别分布不同」与「漂移使预测分布变形」。§5 记录了一个**方向性**新事实。

## 2. 为什么要做这一次标定

T0 报告（`rematch750_class_coverage_audit_20260923.md` §6）：

```
k = 37444 / 14880 = 2.5164
z_c = (Y_c/k - X_c) / sqrt(X_c * (1 + 1/k))
sd(z) = 2.5128   chi2/dof = 6.3175   |z|>2 有 244 类（期望 33.7）   |z|>3 有 110 类
```

其中 **X = RM-LP 在 val 上的逐类预测次数，Y = RM-LP 在 test 上的逐类预测次数**
（两侧同为 RM-LP seed42 这一个 checkpoint；X 由缓存特征 + 线性头在 CPU 上离线重建，
复现 val micro 与记录值差 **2 张图**，落在数值并列敏感度内）。

解读曾是「test 的逐类预测分布不只是 val 按 k 放大」⇒ val 与 test 存在分布差。

**缺的对照是**：该统计量的 H0 方差推导假定逐类计数服从多项分布（Var[z_c] ≈ 1 − p_c ≤ 1）。
图像并非 iid 抽样 —— 近重复图成簇，逐类计数自带超出多项的方差。于是 sd(z) 可能**在
任何两个不相交样本之间**都大于 1，不需要 val 与 test 有分布差。本轮的**唯一目的**
就是量出这个基线。

**设计要点**：对照组 N1 与观察量 O1 的差别**只有一件事** —— N1 的两半来自**同一总体**，
O1 的两半来自 val 与 test。统计量、X 的样本量（都是 14880）、逐类计数的稀疏程度全部对齐。

## 3. 结果

### 3.1 观察量与四个零分布

每项 1000 次重复，种子固定。`p_ge` = 零分布中 **≥ 观察值** 的比例。

| 量 | O1 观察值 | N1 test 14880/22564<br>同尺度同总体 | N2 test 18722/18722<br>k=1 | N3 val 7440/7440<br>域内 k=1 | N1ft RM_FT<br>同 N1 设计 |
|---|---:|---:|---:|---:|---:|
| **sd(z)** | **2.5128** | 1.0556 [0.99, 1.12] | 1.0386 [0.98, 1.11] | 1.0910 [1.03, 1.17] | 1.0479 [0.99, 1.11] |
| **chi²/dof** | **6.3175** | 1.1222 [0.99, 1.28] | 1.0836 [0.96, 1.23] | 1.2036 [1.06, 1.39] | 1.1058 [0.98, 1.25] |
| **\|z\|>2** | **244** | 42 [31, 53] | 39 [27, 51] | 45 [34, 57] | 41 [30, 54] |
| **\|z\|>3** | **110** | 8 [3, 13] | 6 [2, 11] | 10 [5, 16] | 7 [2, 13] |
| **\|z\|>4** | **62** | 2 [0, 5] | 1 [0, 4] | 3 [1, 8] | 1 [0, 4] |
| **p_ge(sd(z))** | — | **0.0000** | **0.0000** | **0.0000** | **0.0000** |

（括号内为 [2.5%, 97.5%] 分位。N1 的 sd(z) 最大值在 1000 次中是 **1.1848**。）

**判定：`EVIDENCE_OF_DIFFERENCE`。** 观察值不在任何一个零分布的量级上。

### 3.2 统计量本身是标定良好的

零分布的 sd(z) ≈ 1.05、chi²/dof ≈ 1.12，与理论值 1 相符；`|z|>2` 的中位数
**42/741 = 5.7%**，理论值 4.55%（期望 33.7）—— 略高于理论，正是「图像非 iid」的
那一小部分超出多项的方差。**这个超额只有 5~12%，不是 150%。** 小计数插值放大的假说被排除。

### 3.3 关键负面结果：分辨力**只存在于 test 侧**

三个**只用 val** 的变体全部落在正常范围：

- N3（val 切两半）：sd(z) 中位数 **1.0910**，与 N1 的 1.0556、N2 的 1.0386 无实质差别。

即：**这个统计量在「同一总体」下永远读到 ≈1，无论那个总体是 val 还是 test。**
它读 2.51 的唯一条件是**两侧来自不同总体**。所以要观测到它，**必须同时有 test 预测**。

**这直接否掉了一个此前写进 GPT-6 brief §12.4.3 的想法**：把它当作「不碰测试集、
规则上合法的本地跨源代理」用于模型选择。**该代理不存在。** 只用 val 时，它恒等于零假设。

### 3.4 两个小的附带事实（都不是病理）

- **零预测类的数量也更少**：val 在 n=14880 下有 **9** 类零预测（7 类 test 侧也为 0，2 类为正）；
  同样本量的 test 子样本零预测类的中位数是 **15**（10 个是结构性零 + 5 个统计性零）。
  `x0_y_pos` 观察值 2，零分布中位数 5、区间 [2, 10]。
- **Δk 不敏感**：N1（k=1.5168）与 N2（k=1）结论一致，说明观察值不是 k 选得不好造成的。

## 4. 预注册判据的兑现

跑之前写定的规则（脚本 docstring 内，跑后未改）：

| 规则 | 结果 |
|---|---|
| `p_ge(sd_z) > 0.05` → O1 落在同总体基线内，T0 不构成分布差的证据 | 未触发 |
| `p_ge(sd_z) <= 0.05` → 显著超出基线，T0 作为「存在分布差」成立，但机制不可辨识 | **触发** |
| 两种情况都不改判据、不派生候选、不占名额 | 遵守 |

## 5. 一个方向性新事实（**弱**证据，不要过度解读）

在**同样本量 n=14880** 下：

| 侧 | 出现过的不同预测类数 |
|---|---:|
| val（真实 14,880 张） | **741** |
| test 的 14880 子样本（1000 次随机切分） | 中位数 **735**，[732, 738]，**最大 740** |

741 高于 1000 次抽样的**最大值**。RM-FT 在 val 上的同一字段是 745（记录值），方向一致。

**读法**：同一个 checkpoint，在 test 上的预测**比在 val 上更集中** —— 不是「塌缩到少数吸引子」
（test 全量 37,444 张仍覆盖 740 类，尾部没丢），而是**小幅收窄**（差 ~6 类，约 0.8%）。

**对 ①② 之争的含义**：这个方向与②（漂移使预测分布变形）**相容**，但**不能证明它** ——
test 真实类别先验若更集中，也会产生同样签名。**不要把它当成结论用。**

## 6. 这一轮改变了什么

| 陈述 | 本轮之后的状态 |
|---|---|
| T0 §6 的过度离散 | **加强**。排除了「小计数假象」，p<0.001，三种设计 + 两条手臂一致 |

| 「val 同样离散 ⇒ 不存在跨源差异」的二分法 | **作废**。正确对照不是「val 对 val 真值」，是「同总体两个子样本」 |
| 11.90pp 本地/平台差的机制 | **仍未明**。本轮只确认 val→test 的预测分布确有真实差异，没给出机制 |

**对搜索策略的影响：无新增本地判据。** 本阶段仍只能由平台名额驱动，

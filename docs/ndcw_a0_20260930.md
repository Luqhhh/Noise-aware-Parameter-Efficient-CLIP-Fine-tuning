## 结果与冻结理由

复用本轮官方 frozen CLIP ViT-B/32 224中心缓存，CPU精确top10、只排除self，
检索阶段记录耗时 **838.73秒**。≥0.94 去重候选69,256对，去除exact后66,799对、
39,218张图；其中跨标签25,937对。39,218张候选训练图逐张SHA256和感知核验完成，
解码失败0。服务重启时核验进程仍存活，复用已有任务，没有重复启动。

全部非exact pair的感知确认率随阈值升高：0.97为42.60%，0.985为66.15%，
0.99为74.30%，0.995为84.23%。首轮一次冻结 **t_medium=0.99 / t_strong=0.995**，
选择高相似度区域，保持Strong的mutual与感知双支持，Medium保留预注册的“至少一个”条件。
依据来自候选和感知曲线，没有训练/平台结果。冻结文件里的`.2625`是比例，等于26.25%。

**全pair确认率不能冒充跨标签冲突纯度。** 跨标签子集在0.99/0.995仅有25.15%/26.25%
感知通过，因此mutual-only Medium仍是结构假设，不能称已证实duplicate或错误标签。
即使放到0.94，跨标签感知通过也只有567对、682张图，仍低于744；这是一项更宽候选
范围的描述，不是第二份训练manifest，不据此改阈值。完整表见
[主曲线](../results/ndcw_a0_20260930/similarity_sweep.csv)和
[跨标签确认曲线](../results/ndcw_a0_20260930/cross_label_confirmation.csv)。

## 门禁、联证与结论

| Gate | Full | Dev |
|---|---|---|
| A：≥0.5% | **FAIL：248<744** | **FAIL：196<670** |
| B：≥50类 | PASS：157 | PASS：133 |
| C：未几乎全被CL拒绝区域捕获 | PASS，见下方限定 | PASS，见下方限定 |
| cap后规模/覆盖 | FAIL：规模仍不足 | FAIL：规模仍不足 |

Full 248张中V1 trust已知220张：CL未保留原标签69张、仍保留151张，
`P(low trust | ND, known)=31.36%`。28张val没有V1 trust；将未知全按low算的
整体区间为27.82%–39.11%。Dev已知196/196，未保留64、仍保留132，low比例32.65%。

**CL保留不等于连续可靠度很高。** 已知220张中184张（83.64%）V1 weight≤0.25；
CL保留的151张平均weight0.2463、中位0.2006。Full原标签kNN agreement平均0.1353，
OOF prototype/ridge agreement（已知220张）分别19.55%/20.45%。
因此注册的CL布尔重叠门虽然通过，不能据此宣称结构性冲突普遍漏过全部置信度方法。
已有OOF表没有原标签概率，248张该概率均未知，不补拟合、不用in-sample概率替代。
逐项已知/未知与unaffected对照见[manifest统计](../results/ndcw_a0_20260930/manifest.json)。

本协议识别到部分非exact、跨标签近重复证据，但**没有达到预注册的规模门**。
cap没有造成淘汰，不是长尾保护抹掉了大规模集合。不能为进入训练把0.97的2048条
跨标签候选直接算成可信near duplicate，也不能把exact的3894张算作新增发现。
关闭当前配方，不降低阈值、不追加参数扫描、不转Drop/Relabel；全数据是否还有
被224中心视图、top10截断或固定指纹漏掉的结构冲突仍未知。

# D 轴（训练侧成像退化增广）本地对照轮：预注册

日期：2026-09-26
性质：**本地测量轮**。**零平台名额**，本机 GPU 约 3 小时。
分支：`clairvoyanttt/d-axis-degradation`
配置：[configs/rematch750_d_deg.yaml](../configs/rematch750_d_deg.yaml)

## 0. 一句话

**本阶段唯一有机制故事直接攻 11.90pp 本地/平台落差的轴，此前完全没实现。**
本轮把它实现出来并**在本地跑一次对照**，量出退化增广的本地代价有多大。
**本轮不作任何晋级决定、不产出提交包、不占名额。**

## 1. 为什么是这条轴

brief §12.4.4 已逐份核对队友 V4 的 A 组（A01–A10：`mixup` / `soft_CE_mixup` /
`cutmix` / `RandAugment`）—— **全是光度+几何增广，没有任何成像退化**
（JPEG 量化、模糊、噪声）。所以 D 轴不重复任何人的工作，且本轮前已扫过全部
`origin/*` ref 确认无人实现。

机制故事：让模型**不依赖来源特有的成像统计**。11.90pp 的落差若部分来自
train/val 与 test 的成像差异，那么只见过干净图的模型在 test 上是带伤作战 ——
它赖以为生的高频线索在那边已被破坏。

## 2. 期望签名是**反向**的（这是本轮的判据难点）

退化增广是**用一点 in-domain 拟合换 source 不变性**。val 与 train 同源
（内容隔离切分，val 来自 `train/`），共享同一套成像统计，所以主动放弃的高频
线索在 val 上本来是**能用**的。**期望签名因此是本地小跌，不是涨。**

同时存在一条**反向力**：本项目是噪声标签，退化增广兼有正则化作用，可能因减少
对错标样本的记忆而**抬高**域内成绩。净符号是经验问题，不是推导得出来的。

**我们自己的数据里有先例**：A1/A2 在正则化邻轴上随强度单调下跌
（MixUp α=0.2 → −0.37pp；α=0.4 → −0.94pp）。

**因此本轮判据必须反向** —— 不能要求「本地涨」，否则这条轴会被自己的判据杀掉。

## 3. 材料与命令

除 `data.train_degradation` 外，配置**逐字镜像** `configs/rematch750_ft.yaml`：
同 seed 42、同 8 轮、同 batch 32、同 `full_finetune`、同 RM-LP init checkpoint、
同 GCE(q=0.5)+CE warmup 2 轮 + 特征蒸馏 2.0。

退化强度（三类分别覆盖压缩块效应 / 镜头模糊 / 传感器噪声）：

| 算子 | 强度 | 施加概率 |
|---|---|---|
| `jpeg`（重编码质量） | 30 – 95 | 0.5 |
| `gaussian_blur`（半径） | 0.3 – 1.2 | 0.3 |
| `gaussian_noise`（σ，0–255 标度） | 2.0 – 10.0 | 0.3 |

算子顺序固定为 `jpeg → gaussian_blur → gaussian_noise`，与 YAML 键序无关。
退化作用在 **PIL 图上、张量化之前**，CLIP 的 resize/crop 与归一化保持原生。

```bash
cd /home/clairvoyant/code/worktrees/clairvoyanttt-d-axis
export PYTHONPATH=reproducibility/aegis_f1
/home/clairvoyant/code/Noise-aware-Parameter-Efficient-CLIP-Fine-tuning/.venv/bin/python \
  -m aegis_clip.cli.rematch train --config configs/rematch750_d_deg.yaml
```

日志：`/tmp/d_deg_train.log`；产物根 `outputs/rematch750/D_DEG/seed42/`。
实测吞吐 400 步 / 122.5s ≈ 3.27 步/秒 ⇒ 约 23.7 分钟/轮。

对照点：**RM_FT**（seed 42，本地 micro 72.8696% / macro 71.8054%），配置完全相同，
只差退化增广。故 `Δ = D_DEG − RM_FT` **只归因于退化这一个变量**。

## 4. 判据（**跑之前写定**）

**本轮没有本地晋级门。** 理由是既有的：lessons §一.1 ——
「本地指标只用于安全审计、复现检查和工程止损（−2pp），**不设本地晋级门槛**」；
且本地→平台斜率尚未测出（`rematch750_transfer_rate_prereg_20260926.md`）。

本轮只记录三件事：

| # | 记录什么 | 用途 |
|---|---|---|
| 1 | `Δ = D_DEG − RM_FT` 的本地 micro 与 macro | 量出退化的本地代价；填入后续迁移率数据集 |
| 2 | 是否**越过 −2pp 本地止损** | 越过则该轴被止损机制机械判死，需在文档中记录该事实（而非宣称方法无效） |
| 3 | 训练是否稳定收敛（loss / 梯度 / 无 NaN） | 能力可用性的证据 |

**明确不做**：不据本轮结果派生候选、不改任何门槛、不产出提交包、不占平台名额。

## 5. 已知软肋（先写明）

| 软肋 | 影响 | 处置 |
|---|---|---|
| **单 seed，而单 seed 噪声 ≈ 0.90pp** | 若真实效应小于噪声，本轮读数不可分辨 | 只作**量级**判断；要定论需 3 seed 配对（brief §12.4.5 的建议） |
| D 轴期望签名本就是小幅负值 | 与噪声同量级时符号都可能读反 | 同上；本轮**不宣称有效性** |
| 这一轮的本地读数**当前无法换算成平台收益** | 斜率未知 ⇒ 不能据此判断该轴对平台有没有用 | 等迁移率标定；本轮的用途是**攒点**，不是决策 |
| A1/A2 已显示正则化在本地是负的 | D 轴可能只是重复同一代价 | 这正是要量出来的东西 —— 量到负值本身是有效信息 |
| 本机 16 轮档曾 2/2 崩 | 8 轮档风险较低但非零 | 记录是否崩；崩则如实报告，不静默重试 |

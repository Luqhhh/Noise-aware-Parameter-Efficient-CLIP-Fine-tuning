## 实现与适配

| 环节 | 本次实现 | 与上游的关系 |
|---|---|---|
| 初始化 | SHA256 校验的 OpenAI 官方 CLIP ViT-B/32；全骨干冻结 | 不加载初赛 `full.pt` |
| 分辨率 | 448，7×7→14×14 位置网格，bilinear / `align_corners=True` / 无 antialias，CLS 保持 | 保留 aligned 策略；448 为偶数网格，不能声称所有旧锚点原样保留 |
| PEFT | 12 blocks 的合并 QKV、attention output、MLP 两个投影，rank 32 / alpha 64 | 48 处注入，包括 K；通过 PyTorch 权重 parametrization 确保 native MHA 真正使用 LoRA |
| 头 | 归一化 cosine classifier，学习 logit scale | teacher 头用于视觉训练 warm start；最终只有一个头 |
| 冻结特征 | 当前阶段已审计的 224 center 特征 | 上游默认 center+flip；本段复用现有缓存，未重编码 |
| 初筛与 teacher | 每类 kNN top 90% 或 agreement≥0.7；teacher 20 轮 | gallery 和监督均来自训练划分；额外排除同内容组邻居 |
| 置信学习 | 每类原标签概率均值作为阈值；最高越阈类一致则保留，未越阈样本保留 | 重现上游源码的 CL-style 简化规则；不冒充 cleanlab 包完整算法，无新增依赖 |
| 伪标签 | 仅回收被筛除样本：teacher=kNN、pmax≥0.7、margin≥0.2 | 不做无条件重标；权重 pmax×sqrt(margin) |
| 样本权重 | 保留样本：0.2+0.8×agreement×sqrt(p_label)×sqrt(margin) | 未回收样本置零；mixup 在混合前分别加权两份监督，避免零权重标签混入 |
| 训练 | RandAugment(2,7)、随机裁剪范围 0.8–1、flip、mixup 0.2、LS 0.1、EMA 0.999、12 轮 | LoRA lr=2e-4 / WD=0；head lr=1e-3 / WD=0.01；OneCycle，warmup 比例 0.1 |
| SWA | 可选：同一轨迹 epoch 4–12 的 EMA 权重在线均值 | 默认关闭，单独 experimental 配置开启；无跨 seed/配置/checkpoint 列表平均 |
| TTA | 短边 resize 448/512/576，各 center crop 回 448，再各做 flip，共六视角，平均 logits | 模型输入恒定 448；不是三个输入分辨率的模型 |
| 均衡 bias | 在官方训练侧 `val_dev` 六视角 logits 上按原标签逐类等质量拟合，之后冻结 | 上游拟合测试预测分布；本仓库禁止该做法，因此改变拟合来源，不在推理时优化 bias |
| 交付 | 一份 selected checkpoint + 已绑定 bias + 确定性推理 + CSV/ZIP 和校验日志 | 不自动上传、不回填平台成绩、不登记为晋级方案 |

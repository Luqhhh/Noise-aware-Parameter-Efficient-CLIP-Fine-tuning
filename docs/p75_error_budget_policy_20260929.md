## 先做一份主要误差预算报告

优先复用**当前阶段**已有、已审计的预测、缓存、类支持量及训练日志。
先在有标签的训练/独立验证数据上定位机制；train 拟合诊断、val 泛化诊断与平台实测
分别标注。按内容组隔离，来源标签不明时将推导的分组标作代理，不能称真实来源。

| 待检验机制 | 最便宜的首批证据 | 必须回答的问题 |
|---|---|---|
| 标签噪声 | 现有跨标签内容冲突、组外近邻/折外支持；必要时核验有限官方训练/验证样本 | 错标与可信难例各占多少？纠正监督能覆盖多少错误？低置信度本身不证明错标。 |
| 类间细粒度混淆 | 当前train_dev候选的独立留出混淆矩阵、top-k及主要类对错例；L05仅作历史参照 | 错误是否集中于足够大的类对/类簇？正确类进入 top-k 是可研究空间，不能当作可达收益。 |
| 长尾 | 当前 train_dev 的逐类支持量与 val 错误数/召回 | 尾类到底贡献多少总体错误？尾类 macro 很差但样本少时，不能冒充数个百分点总体预算。 |
| 来源漂移 | 现有可靠来源字段；或由训练侧定义、冻结的图像属性分组与来源留出诊断 | 哪些来源/代理组失效、规模多大？代理与平台的联系有什么证据，哪些仍未知？ |
| 灾难性遗忘 | 现有同阶段父模型、早期/末期 checkpoint 在同一留出集的逐样本对照 | 有多少父模型或早期能判对、后来判错的图？退化集中在哪些类/来源？不能只看特征漂移范数。 |

先给每个错例标记可支持的机制，报告重叠、去重并集和无法归因部分；**五类不能强行
互斥，也不能直接相加**。训练侧支持数量、验证错例数量和测试等价外推数量分别列出。
选取高置信子集可以辅助归因，但总体效果仍以全部独立验证集为分母，不能只报筛后准确率。

报告用一张表就应能审查：机制、证据路径/协议、观测错例数、重叠、可恢复比例依据、
可能退化的正确样本、净收益区间、平台外推假设、缺证据项、最便宜补证及预计时长。
样本量不足或来源未知时写“未知”，不编造干净标签、测试来源或机制占比。

## 有限探索与完整训练：两级投入

2026-09-29 最新指令收紧旧要求的适用范围：**不要求任何干预之前，就已证明可净修正数千张平台错误**。平台无逐张真值，恢复比例在探索前允许未知；不能形成“没有训练就不知道收益，不知道收益就不准探索”的循环。

有限探索可以承受机制不确定，须同时具备：可观察问题、明确可证伪假设、一个固定配方、明确计算/时长上限，以及预先指定的目标问题与全量修正/退化评估。结果必须能决定关闭或晋级；禁止改名复活已关闭小修、阈值网格或无限补诊断。此条是投入原则，不是任意新实验的自动启动许可。

完整训练需要有限探索出现值得投入的信号：目标问题有成块改善，完整报告全量新增正确/新增错误及macro/micro，并有合理的机制规模与成本依据。一般识别改动应有全量净改善；对于取消疑似无目标图像错误监督的干预，若预先冻结的有效目标候选代理部分明确净改善、全量下降主要集中在疑似无目标代理部分，可保留为待平台验证候选，不以含噪总分下降一票否决。代理不等于干净真值，未命中检测器的补集也不能默认有效。仅疑似污染图的置信度下降而其他部分无识别改善，不支持晋级。预计净修正与风险可以给区间或保留未知；平台迁移假设明确，不把它写成已证实的平台恢复比例。仅训练损失/置信度上升、少量样本CE混入或小切片涨分不足以晋级。

本次[200张图像核验](p75_visual_audit_20260929.md)结束后停止继续拆同一套缓存。若标签状态仍主要无法判断，就明确证据不足以选机制主线，不降低阈值制造可信集、不自动延长核验或投入完整训练。原有已启动实验沿原协议收尾；平台增益只凭平台实测声明。

诊断仅使用官方当前阶段允许的数据与资产；不使用测试图训练、自适应或测试预测分布
调参。来源代理在训练侧定义后冻结，不能为了追平台分反复改分组。最终仍是规则允许的
单 checkpoint、单确定性推理流程。

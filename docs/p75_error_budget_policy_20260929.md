## 目标与已关闭事项

目标是**单位时间找到大幅平台提升**。实验可信度是必要条件，几十个可信的 +0.1pp
局部修改不足以解决约 +8pp 的平台差距。

- 官方已确认复赛 **750 类**；原 1500 类规模只属历史说明，版本问题关闭。
  依据见[比赛规则 §4](../COMPETITION_RULES_AGENT.md#4-数据集信息)和本轮用户确认。
  常规映射/资产血缘校验保留，不再启动类别版本调查。
- 现役 `L05_T14_P060` 固定解码 local macro/micro 为 **75.8265% / 76.6532%**，
  平台为 **66.94797564362783%**；local micro 与平台差约 **9.7053pp**。
  本地验证标签含噪，普通 accuracy 改善不等于平台改善。
- 37,444 张测试图已知正确 **25,068**、错误 **12,376**；75% 需要正确 **28,083**，
  因而需要**净修正 3,015 张**，不是只影响 3,015 张。
  每 1pp 约为 374 张净修正；若机制最多只触及几百个错误，即使全部修好也不足以成为主线。
  数字来源见[已有预算记录](p75_mechanisms_preparation_20260927.md)。

**3,015 是目标缺口，不是一份已有逐图真值的错误清单。** 平台仅有总分回报；
不得把本地错例或可疑训练样本直接称为这 12,376 张平台错误的组成。

## 先做一份主要误差预算报告

优先复用**当前阶段**已有、已审计的预测、缓存、类支持量及训练日志。
先在有标签的训练/独立验证数据上定位机制；train 拟合诊断、val 泛化诊断与平台实测
分别标注。按内容组隔离，来源标签不明时将推导的分组标作代理，不能称真实来源。

| 待检验机制 | 最便宜的首批证据 | 必须回答的问题 |
|---|---|---|
| 标签噪声 | 现有跨标签内容冲突、组外近邻/折外支持；必要时核验有限官方训练/验证样本 | 错标与可信难例各占多少？纠正监督能覆盖多少错误？低置信度本身不证明错标。 |
| 类间细粒度混淆 | 冻结 L05 的混淆矩阵、top-k、主要类对错例及同类差异 | 错误是否集中于足够大的类对/类簇？正确类进入 top-k 是可研究空间，不能当作可达收益。 |
| 长尾 | 当前 train_dev 的逐类支持量与 val 错误数/召回 | 尾类到底贡献多少总体错误？尾类 macro 很差但样本少时，不能冒充数个百分点总体预算。 |
| 来源漂移 | 现有可靠来源字段；或由训练侧定义、冻结的图像属性分组与来源留出诊断 | 哪些来源/代理组失效、规模多大？代理与平台的联系有什么证据，哪些仍未知？ |
| 灾难性遗忘 | 现有同阶段父模型、早期/末期 checkpoint 在同一留出集的逐样本对照 | 有多少父模型或早期能判对、后来判错的图？退化集中在哪些类/来源？不能只看特征漂移范数。 |

先给每个错例标记可支持的机制，报告重叠、去重并集和无法归因部分；**五类不能强行
互斥，也不能直接相加**。训练侧支持数量、验证错例数量和测试等价外推数量分别列出。
选取高置信子集可以辅助归因，但总体效果仍以全部独立验证集为分母，不能只报筛后准确率。

报告用一张表就应能审查：机制、证据路径/协议、观测错例数、重叠、可恢复比例依据、
可能退化的正确样本、净收益区间、平台外推假设、缺证据项、最便宜补证及预计时长。
样本量不足或来源未知时写“未知”，不编造干净标签、测试来源或机制占比。

## 完整训练的启动门禁

完整训练前同时满足以下条件，不能用“已有代码”“算法热门”或“现在有空卡”替代：

1. **规模够大**：机制有逐样本/分组证据，能合理解释测试等价尺度的数千张错误。
   外推依赖的来源比例和迁移假设须明示；仅有几十/几百张错例的影响上限就关闭主线资格。
2. **收益可恢复**：在机制覆盖的错误量 `E` 上，给出有证据的可恢复比例 `r`，并扣除
   原正确样本可能退化数 `D`，估计净修正 `E × r − D` 的区间。主线须有支持**数个百分点**
   的保守预算；目标仍是补足 3,015 张。不能默认 `r=100%`，不能把训练支持图数直接代入 `E`。
3. **廉价证据先过关**：先用缓存诊断或一个有明确时长上限、停止条件的短探针排除假设。
   探针检查指定误差机制及总体修正/退化，不以 +0.1pp 普通本地 accuracy 启动十小时训练。
4. **成本与决定预先写明**：登记唯一首点、GPU/NPU 总时长、所需新缓存/教师成本和关闭条件。
   若新增完整 OOF、多教师或多 seed 才能诊断，先说明其信息价值与更便宜替代；不得自动展开。
   没有机制通过就交付归因报告与未知项，不轮流换模块名继续跑。

机制成立后才选择相应训练范式，允许整体方案变化并声明因果边界；不把主线永久限制在
L05 单变量邻域。必要对照、资产血缘、数值校验和提交检查保留，避免重复全套检查挤占
归因时间。已有实验的 +0.20/+0.30pp 门用于原协议收尾，**不是上述启动门禁的替代**；
平台收益仍只能凭平台实测确认。

诊断仅使用官方当前阶段允许的数据与资产；不使用测试图训练、自适应或测试预测分布
调参。来源代理在训练侧定义后冻结，不能为了追平台分反复改分组。最终仍是规则允许的
单 checkpoint、单确定性推理流程。

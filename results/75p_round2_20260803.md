## 核心判断
信任机制（cvt_v1 加权 + 伪标签软修正）只应用在 LoRA 子阶段（8 epoch），
而 50 epoch 的冻结父模型（E2，噪声盲）主导分类器学习。**让父模型噪声感知
是最大的未用杠杆**。

## 已执行实验

### T1: 信任感知 E2 父模型（丢弃版 E2_MIXUP_CE5_REBUILD_W060_TRUST）❌
- 配置：E2 配方 + trust（selection_threshold 0.60 硬丢弃、min_weight 0.6、
  correction_start_epoch 2）
- **关键提速**：`use_cached_training: true`（冻结骨干 + CLIP 默认预处理 ==
  特征缓存预处理，信号等价），epoch 从 >15min 降到 ~10-20 秒。
- **结果 ❌**：最佳 clean-core 0.7835（ep23），低于噪声盲 E2 的 0.8088。
  硬丢弃 27.5% 样本破坏数据覆盖 → 父模型更差。**丢弃版关闭。**

### T1b: 连续加权版（E2_MIXUP_CE5_REBUILD_W060_TRUST_CONT）⚠️ 与噪声盲持平
- 修正：保留全部数据，连续权重 0.6+0.4*clean ∈ [0.62,1.0]，加权从 epoch 6、
  修正从 epoch 5。
- 完成 50 epoch：best clean 0.8085（ep34），与噪声盲 E2（0.8088）持平。
- **结论 ⚠️**：父阶段 trust 加权没有带来明确 clean-core 优势（丢弃版 0.7835
  更差）。父模型主要价值在全部数据 + GCE + MixUp；trust 加权在父阶段收益
  不显著。父实验方向关闭。

### T2: flat-LR 子模型（F1_VISUAL_LORA_CLEAN_CORE_REBUILD_R1_W060_A12_CORR_FLAT）
- 理由：A12_CORR 的 LoRA 适应很小（drift 0.0064），LR cosine 在 8 epoch 内
  衰减到 ~0。schedule_epochs 16 保持 LR 在 epoch 8 仍在初始的 50%，提取更多
  LoRA 收益。
- 基座：噪声盲 E2（clean 0.8088，已验证最佳父模型）。8 epoch，LoRA 12 block
  rank 8，correction epoch 2，feature distill 2.0。
- **完成 8 epoch**：best clean 0.8193（ep7），A12_CORR 0.8183 → **+0.1pp**，
  promotion PASS（selector_gain +0.0105、raw_gain +0.0098）。flat LR 全程每
  epoch 小幅领先 A12_CORR。
- **但 M1+flip 融合点持平**：平台验证协议 l040/f050 上 flat clean 0.8249 vs
  A12_CORR 0.8251（略低 0.0002）；flat 本地最优 l035/f060（0.8261）——战役
  已证明 l035/f060 平台更差，不采用。
- **结论 ⚠️**：bare clean +0.1pp 未转化为 M1+flip 优势；两个 checkpoint 在
  平台验证协议上基本等效。flat 包作为独立第二候选交付，供平台实测。

### 负结果：clip_letterbox 推理（已关闭）

  raw 0.6704 / clean 0.7717（全部指标低于 center-crop）。

  依赖 CLIP 原生预处理，letterbox 改变输入分布 → 损害。关闭。

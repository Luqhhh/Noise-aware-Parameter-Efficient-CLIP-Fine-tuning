# 75+ 平台优化方案（2026-07-31 会话提出）

## 1. 现状与目标

| 项 | 值 |
|---|---|
| 平台最佳 | 67.2848%（W050 + M1/Flip + prior 0.75） |
| 本地 raw（M1+flip，带噪 val） | 72.28%（W050） |
| local→platform gap | ~5.0pp（prior 校准前 8.35pp） |
| 短期目标 | 70+（细扫 + 重调 M1 + 少量训练改进） |
| 冲刺目标 | 75+（需突破性杠杆） |

**硬约束**：本地 raw 带噪 val 72.28% 而平台 67.28%，且平台标签干净——说明
**平台测试分布明显更难**。冲刺 75% 需要把本地 raw 推到 ~80%+（若 gap 保持 5pp），
这必须靠突破性杠杆，不是微调。

## 2. 已确认的杠杆（按预期收益排序）

### ① 高分辨率微调（规则已确认允许）—— 最大单杠杆，+2~5pp

CLIP ViT-B/32 在 224px 训练。**插值位置编码后喂 336/448px** 是细粒度任务的
公认提升手段。用户已确认该技术符合赛规（仍是 ViT-B/32 权重，位置编码插值是
标准微调，不改变架构族）。

- 预期：本地 raw 72% → 76-78%，平台 ~70-73%
- 副作用：M1 attention crop、flip、prior 强度均在 224px 调参，需在高分辨率下重调
- 实施步骤：
  1. 先做小规模验证：`build_from_checkpoint` 加载 ViT-B/32，将 `visual.positional_embedding`
     从 7×7=49 插值到 10×10=100（336px）或 14×14=196（448px），在 val 上跑 global raw
     与 clean-core，看是否明显提升
  2. 若验证通过：训练时用高分辨率（训练管线需支持分辨率参数 + 位置编码插值）
  3. 重调 M1 定位参数（crop/top-k）与 flip 融合权重
- 风险控制：插值要可复现、可审计；训练与推理分辨率必须一致

### ② 更激进的 CLIP 适配 —— +1~3pp

F1 当前只 LoRA 最后 4 个 block、rank 8（~40 万参数，占 0.5%）。方向：

- **LoRA 全部 12 block**（而非提高单个 block rank——R16 rank 翻倍已证明会损害
  M1 局部推理）
- **全量微调 visual tower**（配合强噪声保护：trust 加权 + 特征蒸馏锚定）
- 注意：R16（rank 8→16）负结果说明"容量增加方向"要谨慎，换"覆盖面"
  （更多 block）而非"单点容量"
- 每步都要在 M1+flip 指标上验证（不只是全局 clean-core）

### ③ 更好的噪声处理 —— +0.5~2pp

- 当前 trust bundle（cvt_v1）是早期跨折 OOF 信号
- **用训练动态 / F1 自己的 OOF 重估噪声** → 更好的样本权重 → 更好的训练
- **pseudo-label 修正**：bundle 里有 `pseudo_label` 但 F1 配置
  `correction_start_epoch: 99` 从未启用，可试探有上限的软修正
- 更多数据方向已到收益递减（trust 阈值 0.70→0.50，本地 +0.15pp，平台 W050
  反而略低于 W060），优先换方向

### ④ 更好的局部视图 / 推理 —— +0.5~1.5pp

- M1 参数（crop160/top5/local0.40/flip0.50）在 **R1** 上调的，**在 W060/W050 上
  重调**可能更优（sweep_localization，纯推理，快）
- `--input-resize-mode clip_letterbox`（保整图不裁剪）未测过
- 高分辨率输入下的局部裁剪需重新设计

### ⑤ 校准精修 —— +0.2~0.5pp

- per-class 置信度 / 温度校准，在 prior 0.75 基础上再抠
- 强度细扫（0.6 / 0.75 / 0.8 / 1.0）已测，0.75 最优；可在 0.65-0.85 细扫定位峰值
- 收益小但零训练成本

## 3. 执行路径

| 阶段 | 动作 | 预期收益 |
|---|---|---|
| 阶段 A（立即） | 强度细扫（W060+0.6/0.8 已生成）+ M1 参数在 W060 重调 | +0~0.8pp |
| 阶段 B（核心） | **高分辨率验证**（224→336/448 插值，val 上测 raw/clean-core） | 决定是否投入 |
| 阶段 C | 高分辨率训练 + 重调 M1/prior | +2~5pp |
| 阶段 D（并行） | 更多 block LoRA / 噪声重估 / pseudo-label | +0.5~2pp |

## 4. 决策门

1. **阶段 B 门**：高分辨率验证若本地 raw ≥ 74%（相对 224px 的 72.3%），值得投入
   完整训练；否则退回 ②③
2. **上传门**：候选包必须本地 M1+flip 指标 ≥ 当前最佳 **且** 平台实测验证
   （本地 ±0.1pp 差异不可靠，见 W050 教训）
3. **规则门**：高分辨率 = 位置编码插值 + 同分辨率训练/推理，不使用外部数据、
   不跨模型融合、不做测试时训练
